## Forecast  

Forecast is a module that trains one or multiple ML models to make a forecast from the loaded dataset.

### Content

- Load a dataset
- Data preprocessing (cleaning, anomalies and level shifts)
- Machine learning model selection
- Feature Engineering Generation
- Forecast

### Details 
This module performs forecasting through different machine learning models, showing the forecasts of a time series and the performance of each model.

### How To
-   Preprocessing: this option will analyze and correct missing values, anomalies and level changes for each time series.
-   Feature engineering: from a time series different features will be generated, including some columns of the dataset optionally. This step is only necessary if you use a Random Forest or XGBoost model for forecasting.
-   Forecasting: once the target time series and ML models are selected, the forecasts and performance of each model will be displayed according to the selected dates and forecast horizon.
