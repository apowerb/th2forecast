## Forecasting

This session provides users with tools to manage and visualize forecasting pipelines, enabling effective analysis and prediction of future trends.

### Content

The content is composed of two main parts: Forecasting Pipelines and Forecasting Viewer.

### Details

##### Forecasting Pipelines

-   This section offers users the ability to visualize all created pipelines as cards, presenting essential details such as the pipeline name, the types of data sources for input and output, target groups, targets, forecast duration, and creation date.

##### Forecasting Viewer

Allows users to explore and visualize historical data and predictions along with high and low confidence intervals.

-   **As_of :** Select the pipeline execution date

-   **KPIs :** Choose a key performance indicator (KPI)

-   **Model:** Select a prediction model

-   **Aggregation :** Choose an aggregation type (sum, average, mean, etc.)
